# Minimal Sparkling Android Example

This application is generated from `create-sparkling-app` and intentionally contains no feature integration. It is the runnable baseline for the later Storage example.

From the repository root, build the Lynx bundle with:

```bash
pnpm --filter storage-quickstart build
```

With an Android emulator running, install and launch the generated application with:

```bash
pnpm --filter storage-quickstart run:android
```
